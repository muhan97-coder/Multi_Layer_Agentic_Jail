# Free-tier cold-start candidate

This bundle is an offline delivery candidate, not a published release, an unlock
token, or evidence of paid-model performance. It includes no personal memories,
credentials, operator environment, or optional upper-tier payload.

T0 previews the synthetic queue and replays a mock planning request without
writes. T1 produces a mock SI proposal in an explicit temporary jail; it does
not apply a change. T2 reads synthetic ledger joins, costs, episode accounting,
and a bounded source manifest. Synthetic cost entries are not invoices.

Run the cold-start checker from a separate, new temporary directory. A missing
component, modified shipment, external access, or incomplete receipt is NO-GO.
Passing this check alone does not authorize publication or complete Stage C.

The real tick's master-OFF path retains its production human-HALT metadata
check. An active human HALT refuses the smoke test; it is never mocked away.
Python audit hooks observe ordinary file/network/process effects, not every OS
metadata access and not malicious native code. They are not a security sandbox.
